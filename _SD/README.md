# SD-комплект HMM2 VDAC4, сборка 134

**HMM2.DAT с игровыми ассетами не включён. Без него игра не запустится.**

1. Скопируйте содержимое этой папки `_SD` в корень SD-карты.
2. Добавьте свой `HMM2.DAT` в `GAMES/VDAC4/HMM2 VDAC4/` рядом с ELF и SPG.
3. Из Wild Commander запустите `GAMES/VDAC4/HMM2 VDAC4/_HMM2.SPG`.

Совместимый полный архив: **547 492 852 байта**.
SHA256: `d0c1390d5bbbc1c6e227a8775f3ff595c7588a0412e845c48ee6c7d40be7a236`.
Архив содержит графику, карты, музыку, звуки и ролики; его нужно иметь отдельно.

В Git включены `HMM2.ELF`, `_HMM2.SPG`, прежний вспомогательный `HSD.ELF`,
звуковой модуль `WC/ESP/OGG.ELF`, начальные настройки и лицензии.
SPG содержит встроенную заставку загрузчика. Страница `#F7` с путями
Wild Commander зарезервирована и не используется кэшем DAT. Личные сохранения и индекс в комплект не входят.

Контрольные суммы опубликованных файлов находятся в `SHA256SUMS.txt`.
Игра сделана для **ZX Evolution с VDAC4** на основе **OpenHMM2 / fheroes2 1.1.17**.
Ссылки на источники: [README проекта](../README.md#источники).

Изменения и замеры опубликованной сборки: [BUILD134.md](../docs/BUILD134.md).
