# Сборка 161

Игра для ZX Evolution с VDAC4, сделана на основе OpenHMM2 (fheroes2 1.1.17).

- При скролле фон переиспользует участки в RAM_G через `CMD_MEMCPY`.
- При ходьбе существующие команды окружения сохраняются, пока геометрия карты позволяет обновить только героя.
- Задача курсора восстанавливается после прерванной передачи команд FT812. Сцену Blue Water проверили с закрытием описания навыка и последующим движением курсора.

На Ево при повторной проверке первой карты среди монстров средний кадр
ходьбы занял 33,66 мс, или 29,71 кадра/с. Выборка включает 400 активных кадров.
Оба маршрута пройдены до конца.
