# Сборка 159

Игра для ZX Evolution с VDAC4, сделана на основе OpenHMM2 (fheroes2 1.1.17).

- После «ОК» в описании навыка выбор снова получает собственные команды
  курсора FT812. На сцене Blue Water курсор сразу следовал за мышью,
  а «Изучить» повышал навык. Пользователь подтвердил исправление на Ево.
- Z80 опрашивает ввод между полными ответами SD и блоками предзагрузки.
  Страница `#F7` остаётся зарезервированной для Wild Commander.
- В списке сохранений используется дата с годом. Сохранения сортируются
  по убыванию даты, список карт прокручивается колесом мыши.
- В 157 снижены требования к непрерывному участку памяти при загрузке
  больших карт. «Равнины Эйкона» проверены в ESP-эмуляторе с PSRAM 7 МиБ.
- Русские меню и субтитры кампаний используют локальные ресурсы. Проверенный
  DAT содержит расширение для прямой загрузки русских атласов в RAM_G.

На сцене Blue Water сравнили команды курсора старого и нового ELF после
закрытия подсказки. В Slot1 пять фаз прошли без расхождений, опозданий
и переполнений. ELF прошёл проверку 38 импортов ABI и ограничений кэша ESP.
